# T3: Android logger

## Done
- `app/src/main/cpp/platform/log/AndroidLogger.{h,cpp}` (new, nothing else touched).
- `opsu::AndroidLogger : ILogger` over `__android_log_print`:
  - trace/debug/info/warn/error -> VERBOSE/DEBUG/INFO/WARN/ERROR.
  - Exception overloads append `": " + e->what()` to the logcat message.
  - Logcat tag: fixed tag `"opsu"` by default (constructor and `installAndroidLogger`). The caller's tag is prefixed to the message as `[tag] `, except when it is one of Trace/Debug/Info/Warn/Error (the logcat priority already shows the level). Since `opsu::Log` always passes one of those five, its lines show as plain `opsu` + message; other callers' tags are kept as a prefix. Passing `""` as `logcatTag` gives pure tag passthrough (the caller's tag becomes the logcat tag, no prefix).
  - Messages over ~3500 bytes are split into several logcat lines (logd truncates near 4 KB).
- `setSaveToFile(bool)` matches DefaultLogger: lines `HH:mm:ss.SSS tag: message`, then `what()` on its own line, flushed on every write. Like Java (`Options.LOG_FILE` = `opsu.log`, truncated at open, "Run date:" first line), the file is `<logDir>/opsu.log`, truncated once the first time saving is turned on. Turning it off stops writing; turning it on again keeps appending.
- The log folder is a constructor argument (created if missing); empty = no file logging. No hardcoded paths.
- Thread-safe: logcat calls are lock-free; the file and the flag are behind a mutex.
- `AndroidLogger* installAndroidLogger(logDir, saveToFile = false, logcatTag = "opsu")` creates the logger and calls `Log::setLogger`.

## Differences from the task text (please check)
- `Log::setLogger` takes a raw `ILogger*` and does not own it (the task says `make_unique`). The helper keeps the instance alive in a static; calling it twice swaps it safely.
- The log FILE format is independent of the logcat tag and is unchanged (`HH:mm:ss.SSS Info: message`, with the caller's tag as given).

## How to test on a device
In `main.cpp` / JNI init (not edited by me), with the app's files dir:
    opsu::installAndroidLogger(configDir, /*saveToFile=*/true);
    opsu::Log::info("hello");
Then run `adb logcat -s opsu`. (If you installed with `logcatTag = ""`, use `adb logcat -s Trace Debug Info Warn Error` instead.) Check the file with `adb pull` from the folder you passed (use a path the app can write).
