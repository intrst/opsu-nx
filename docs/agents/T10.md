## Done (milestone 1)
Files: `core/include/opsu/options/{Options.h,OptionGroup.h}`, `core/src/options/{Options.cpp,OptionGroup.cpp}`, `core/tests/test_options_t10.cpp`.

- `GameOption`: all 75 Java enum constants (NULL + 74) **in Java order** (= order of opsu.cfg). The entry table
  (name, config key, description, default, min, max, restart flag) was generated from `Options.java`, not typed by hand.
  Java names kept (`GameOption::MASTER_VOLUME.getIntegerValue()`), plus `values()`, `ordinal()`, `constantName()`, `fromConstantName()`.
- Per-option behaviour ported: `setValue` (clamp, dirty, volume seam), `toggle` (FULLSCREEN / SHOW_FPS / SHOW_UNICODE overrides),
  `selectItem` (resolution, skin, FPS, screenshot format), `getItemList`, `getValueString`, `write`, `read`, `matches`, `isCustomized`, `resetToDefault`.
- Static facade `Options::` with every accessor of the Java (getMusicVolume, isSliderSnaking, getFixedCS, setGameKeyLeft, getMobileUIScale(float), ...).
- `OptionGroup` + `OptionGroup::allOptions()` / `loaderOptions()` (same groups and order as the Java; `desktopOnly()` driven by a seam).
- Thread safety: atomics per option, a mutex for strings/keys/seams; getters are safe from audio/download threads.
- `Options::setSeams()`, `Options::resetForTests()`. No I/O at static-init time (state is built lazily on first use).

## Done (milestone 2)
- `OptionsPaths` (configDir, dataDir, cacheDir, localDir, downloadDir; default constructor = a folder under the system temp dir) and
  `Options::init(const OptionsPaths&)`. `init` does **no file I/O**; it also forgets directories read from the config earlier, so call it before `parseOptions()`.
  Before `init`, the path getters return "" and `parseOptions/saveOptions/flush*` do nothing (no I/O).
- Derived names, as the Java: `getLogFile` (cfg/opsu.log), `getOptionsFile` (cfg/opsu.cfg), `getOldOptionsFile` (cfg/../.opsu.cfg), `getBeatmapDB/getOldBeatmapDB/getLocalBeatmapDB`,
  `getScoreDB/getOldScoreDB/getLocalScoreDB`, `getNativeDir`, `getTempDir`, `getConfigDir/getDataDir/getCacheDir`. All return absolute `/`-paths without a trailing slash.
- Directory getters with the Java fallback/creation logic: `getBeatmapDir` (-> data/Songs, created), `getImportDir` (-> data/Import, created), `getSkinRootDir` (-> data/Skins, created),
  `getScreenshotDir` / `getReplayDir` (name only, not created), `getSkinDir` ("" = default skin), `getDownloadDir`, `getFFmpegLocation`.
  The six directory options (BeatmapDirectory ... FFmpegPath) now read/write through them.
- `parseOptions()`: line by line (`\n`, `\r\n`, lone `\r`), trim, lines < 2 chars or starting with `#` skipped, first `=` splits, unknown keys ignored,
  `NumberFormatException` and other errors logged with `Log::warn` and skipped, `SliderStyleVersion` migration (one-time reset of the slider options, then rewrite), `SongSortOrder`.
  UTF-8 decoding with U+FFFD for bad bytes (like the JDK). Missing file -> defaults are written.
- `saveOptions()`: header (`# opsu! configuration`, `# last updated on EEEE, MMMM dd, yyyy`, blank line), `SliderStyleVersion = 1`, optional `SongSortOrder = X`,
  then `<DisplayName> = <write()>` for every option in Java order (NULL skipped). UTF-8, `\n` line endings, no BOM. Temp file `opsu.cfg.tmp` + fsync + rename (remove + retry if the rename fails). Serialised by a mutex.
- `flushIfDue()` (400 ms debounce, `nowMs` seam) and `flushNow()`.
- Tests added: no I/O before init, derived paths, lazy directory creation, config fixture (CRLF, blanks, comments, unknown keys, malformed numbers, out-of-range, `=` inside values, UTF-8), migration,
  exact written format and order (78 lines), write -> reset -> read round trip of every option, debounce, concurrency with save/parse.

## main.cpp hooks (exact lines)
```cpp
#include "opsu/options/OptionsWiring.h"
// ... once at start-up, in this order (init -> seams -> parse -> hosts):
opsu::OptionsPaths paths;
paths.configDir = paths.dataDir = paths.cacheDir = "/storage/emulated/0/opsu";   // the Java used one "opsu" folder for all three
paths.localDir = internalFilesDir;                       // app-private files dir (e.g. app->activity->internalDataPath)
paths.downloadDir = "/storage/emulated/0/Download";
opsu::Options::init(paths);                              // no I/O

opsu::OptionsSeams seams;
seams.isTouchPlatform = [] { return true; };             // enables isMultitouchGameplay()
seams.screenWidthInches = [app] {                        // UI scale / playfield scale defaults (<= 6.0 in = phone)
    int dpi = AConfiguration_getDensity(app->config);    // density bucket; JNI DisplayMetrics.xdpi is more exact
    return (dpi > 0 && app->window) ? float(ANativeWindow_getWidth(app->window)) / float(dpi) : 10.0f;
};
// seams.sendBarNotification / resetFPSDisplay / loadUnicodeGlyphs / requestSkin / listSkinDirectories: set when UI, Fonts, SkinSwitcher
// and SkinLoader exist (listSkinDirectories defaults to "no skins", so the skin dropdown only shows "Default" until then).
opsu::OptionsWiring::wireAudioSeams(seams);              // volume changes reach MusicController
opsu::Options::setSeams(seams);                          // before parseOptions: the screen defaults are resolved here
opsu::Options::parseOptions();                           // reads opsu.cfg (writes the defaults if there is none)

opsu::MusicController::setHost(opsu::OptionsWiring::musicControllerHost(/* theme beatmap getter */));
opsu::SoundController::setHost(opsu::OptionsWiring::soundControllerHost());

// every frame:           opsu::Options::flushIfDue();
// on pause / exit:       opsu::Options::flushNow();
// instead of HitObject::init(w, h, scale):   opsu::OptionsWiring::initHitObject(w, h);
// startup import:        opsu::OptionsWiring::OptionsDownloadImporterEnv env(unpackSkinsFn, unpackBeatmapsFn);
//                        opsu::DownloadImporter::importAll(env);
```
Call `Options::setSeams()` again after wiring more seams (it replaces the whole struct: fill one `OptionsSeams` and set it once, or keep your struct and set it again).

## Deviations from the Java
- `GameOption.NULL` is `GameOption::NULL_OPTION` (`NULL` is a C++ macro). `constantName()` still returns "NULL".
- Internal options have empty `getName()/getDescription()` instead of null; `matches()` is ASCII-only case folding.
- `getItemList()` returns an empty vector where Java returns null.
- `selectItem` with an out-of-range index is ignored (the Java would throw later with ArrayIndexOutOfBounds).
- `setDisplayMode` drops the LWJGL `org.lwjgl.opengl.Window.undecorated` system property (desktop LWJGL only).
- `getSavedSortOrder()` returns "" for "none" (Java: null); `setSavedSortOrder("")` is ignored like `null`.
- Milestone 2: `OptionsPaths`/`init` replace the static `./opsu` paths; the config folder is created by `saveOptions` (`create_directories`; the Java relies on it existing);
  directories are created with `create_directories` (the Java used a single-level mkdir); the osu! installation lookup stays null (as in the Java port);
  `getDownloadDir` reads `$HOME/Downloads` (desktop seam only), else the relative "Download"; failures use `Log::error` instead of `ErrorHandler.error`.
- A `SongSortOrder =` line with an empty value is treated as "none saved" (Java keeps an empty string and writes it back).
- Relative paths read from opsu.cfg are resolved against the working directory (the Java fake `File` searched shared/external/local storage).
- Faithful quirks kept on purpose: `toggle()` does not mark the options dirty; `read()` does not fire the volume seam and does not mark dirty;
  `read()` of a number out of range is ignored (not clamped); `hasFullscreenDisplayMode()` is always false, so FULLSCREEN can never be turned on.

## Decisions from the project owner
- Key names: keep the built-in table (A-Z, 0-9, F1-F12); only names known to match libGDX `Keys.toString` are added; unknown names fall back to Z/X; no `keyName` seam from main.cpp (the seam stays for tests).
- libGDX 1.14.2: key numbering as used. The reserved-key list has no Ctrl, so the 129/130 vs 113/114 difference does not matter here.
